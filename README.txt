SHOPMAIL V2
===========
This version adds real front-end product detail pages and a persistent shopping cart.

Open index.html in a browser.

Working:
- Product cards open product detail pages
- Quantity selector
- Add to Cart / Buy Now
- Cart page with item totals and remove buttons
- Cart count
- Cart persists in browser localStorage
- Search
- Responsive mobile layout
- Red buttons throughout

Still needed for a production store:
- Real database/backend
- User accounts
- Real product images/catalog
- Checkout/order API
- Razorpay/Stripe payment integration
- Admin dashboard
- Shipping/order tracking
- Domain + hosting
